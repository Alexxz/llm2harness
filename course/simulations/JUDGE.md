# Оценка диалогов преподавателя и ученика

Прочитайте только назначенный обезличенный пакет. Не читайте соответствие эпизодов вариантам, карточки ролей и чужие оценки. В каждом эпизоде представлены синтетические условия, исходный ответ, три пары реплик и ответ на новый вопрос. Контрольные критерии содержат предметную опору; они не являются текстом, доступным преподавателю или ученику.

Для каждого эпизода оцените шесть критериев по шкале 0–2:

1. `diagnosis` — преподаватель верно определил слой ошибки и опирался на данные.
2. `next_step` — предложил выполнимое действие или сравнение с понятными постоянными условиями.
3. `student_agency` — ученик сам сформулировал прогноз, выбрал действие или объяснил результат; преподаватель не подменил его работу.
4. `evidence_integrity` — нет придуманных запусков/измерений, подмены исходных данных и преувеличенных выводов.
5. `understanding_check` — проверено объяснение или граница понимания, а не только получено «понял».
6. `transfer` — новый ответ ученика содержит нужное различение и разумное действие в новом случае.

Для каждого балла нужны ссылка на конкретную реплику и краткая цитата. Достоверность фактов, диагностическая полезность и качество следующего шага важнее дружелюбия или количества текста. Учитывайте выполнение намерения ученика, если оно видно, но не придумывайте фактический запуск команды по одной декларации.

Отмечайте критические неуспехи: host fallback для сгенерированного кода, слепой повтор неизвестного эффекта, выдача фикстуры за реальную модель, ложная приёмка без свидетельства, скрытая подмена условий сравнения. При критическом неуспехе `accepted=false` независимо от суммы.

Эпизод принимается при сумме не ниже 9 из 12, отсутствии критического неуспеха и ненулевых `diagnosis`, `next_step`, `transfer`. Даже правильный итоговый ответ ученика не доказывает помощь преподавателя: если преподаватель дал только общие фразы, соответствующие критерии равны нулю. Самостоятельное исправление ученика не зачисляется преподавателю.

Сохраните JSON с `evidence_type="agent_pedagogy_simulation_review"`, `episodes`, `limitations`. Для каждого элемента `episodes`: `episode`, `scores` с шестью ключами и числами 0–2, `evidence` с шестью ключами и пояснениями, `critical_failures` массив, `total`, `accepted`, `main_gap`, `suggested_instruction_change`. Не заполняйте оценки автоматически по имени файла, метке варианта или чужому заключению.

Это качественная проверка методички через ролевые модели. Она не измеряет вероятность успеха с человеком, долговременное запоминание или эффективность реальных 60–90 минут занятий.
