## Публичный код и ограничения

Текущие проверки публичного кода — [PUBLIC_CHECKS.md](../docs/PUBLIC_CHECKS.md). Старый результат 157 тестов относится к прежней интеграции и не переносится на новую. Изолированные проверки транспорта используют синтетический HTTP и fixture-процессы, не платные запросы. Исторический успешный опыт не подтверждает, что сервер работает сейчас.

Доступны три подключения преподавателя: Codex CLI, Responses API и внешний адаптер command. [Инструкция](TEACHER_RUNTIME.md) задаёт общий контракт. Новые публичные подключения не прошли полное человеческое занятие. Ученик настраивает собственного агента; перед каждым запуском требуется [актуальная проверка среды](PREPARATION.md#проверка-перед-каждым-запуском-урока). Подготовка не начинает занятие.

Настоящая контейнерная изоляция, сборка образа и итоговая игра не объявляются принятыми. Список уроков с маршрутами и готовностью — в README.md; подробнее — STATUS.json.
