# Памятка по интерфейсу

## Один разговор

Все вопросы и ответы преподавателю — **в канале преподавателя**. Терминал не является вторым чатом. Специального слова для продолжения нет: расскажи, что увидел, или задай вопрос. Преподаватель сам читает журнал опытов.

## Простые клавиши

- **F2** — материалы преподавателя: объяснения и короткие задания.
- **F3** — терминал ученика: команды опытов.
- **Ctrl+h** — открыть помощь.
- **Esc** — закрыть помощь.
- Колесо мыши — прокрутить текст; щелчок — выбрать окно.

F2 и F3 нажимаются один раз. Последовательность с Ctrl+b учить не нужно.

## Команды

В терминале ученика show показывает подготовленный текст, help — список команд. Другие действия изучаются по мере курса.

В материалах преподавателя работают только навигационные команды: /lesson перечитывает введение, /basics открывает эту памятку, /exit закрывает учебное окно. Обычная фраза здесь не отправляется преподавателю: напиши её в чате.

Журнал и исходные данные сохраняются. Учебный сервер tmux использует собственную конфигурацию; личные настройки не меняются.
