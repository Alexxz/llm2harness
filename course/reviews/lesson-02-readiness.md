# Проверка подготовки урока 02

Обновлённые требования закреплены в AUTHORING.md, COURSE_SPEC.md, METHODOLOGY.md и VALIDATION.md. Реестр проверяет delivery_contract=interactive-v1; наличие учебных файлов и технические проверки отделены от педагогической готовности.

Отдельный агент-рецензент прочитал новый урок и нашёл один интеграционный блокер: edit сохраняет перевод строки после последнего «Ответ:», а готовый variation его не содержал. Это изменяло дополнительный фактор в raw completion. Исправление: baseline/variation/replaced-fact заканчиваются одинаковым переводом строки; неполная первая фраза first-turn остаётся без него. Полный пилот проверяет буквальное second_prompt.endswith(variation_prompt) и включение целого настоящего первого выхода. Других блокеров по материалам рецензент не нашёл. Это ревью автора, не слепая оценка ученика.

Реальные авторские запросы — evidence/lesson-02-live-pilot.json:

- С именем Плюш ответ начинается «Кота зовут Плюш».
- Без строки имени — «Кота зовут Котик»: имя не поддержано входом.
- После замены факта ответ называет Бублика.
- Самостоятельное продолжение первой фразы создало имя Котя.
- Через настоящий edit полный первый выход включён во второй запрос; ответ — «Кота зовут Котя».
- Без этой истории тот же последний вопрос снова получает Котик.

Это наблюдения одного профиля с 0/42/24, не обязательные ответы нового ученика и не общая оценка качества модели. Неуспех извлечения остаётся допустимым и разбирается по входу.

results/lesson-02-terminal-pilot.json подтверждает настоящее tmux-окно, видимое подготовленное начало, show без вызова преподавателя, настоящий запрос к ядру и очистку процессов. Преподаватель в этой UI-проверке синтетический, поэтому её нельзя выдавать за проверку объяснений.

Объяснения отдельно проверены через настоящий codex в results/lesson-02-teacher-review.json: на синтетический вопрос о «забытом» имени преподаватель различил переданный контекст и неподтверждённое продолжение; на вопрос о ручной вставке объяснил хранение текста и передачу в новый запрос, привязав разбор к реальному первому/второму выходу. Тестовые ответы не отправлялись в учебный диалог человека.

116 тестов прошли, структура 19 единиц валидна. Урок 02 технически подготовлен для человеческого пилота; понятность нового занятия для человека ещё не подтверждена. Основная база перед изменением сохранена в Git master, коммит c82d6f9.
