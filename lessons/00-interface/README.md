# Урок 00. Знакомство с лабораторией

## Цель

Освоить области терминала, выбрать заготовку и получить первый ответ модели. Устройство модели здесь не изучаем.

## Перед началом

Нужны tmux, системный Python с зависимостями, настроенный преподаватель и локальная модель. Команда проверит текущее окружение до создания сессии; терминал — не меньше 100×26.

```bash
./lab classroom start --lesson 00 --split
```

## План занятия

Две области → подсказка → выбрать пресет и сразу получить ответ. Между загрузкой и первым запуском отдельного вопроса нет.

## Опыты

### Две области

Слева находится преподаватель: здесь ты читаешь объяснения, задаёшь вопросы и обсуждаешь наблюдения. Справа находится лаборатория — программа для работы с исследуемой моделью. В рамке «**Вход модели**» находится текст, который можно будет отправить модели, а в рамке «**Выход модели**» появится её ответ. Сейчас запроса ещё не было. `F3` выбирает лабораторию, `F2` возвращает к преподавателю; выбранная область получает фокус клавиатуры.

**Попробуй**

Нажми `F3`, посмотри на поля «**Вход модели**» и «**Выход модели**», затем вернись через `F2`. Пока ничего не запускай.

**Вопрос после опыта**

В какой области ты будешь менять текст для модели, а в какой — задавать вопросы преподавателю?

### Подсказка

**Подсказка** — справка о клавишах лаборатории. Она открывается по `F1` и временно занимает правую область. `Esc` закрывает её и возвращает поля «**Вход модели**» и «**Выход модели**» без изменения их содержимого. Подсказка ничего не отправляет модели. На этом шаге учимся только открывать и закрывать справку; выбор пресета разберём следующим шагом.

**Попробуй**

Нажми `F3`, открой подсказку через `F1`, прочитай её заголовок и закрой через `Esc`. Вернись в `F2`.

**Вопрос после опыта**

Какая клавиша открыла подсказку и какая вернула тебя к рабочим полям? Изменилось ли содержимое поля «**Вход модели**»?

### Выбрать пресет и получить ответ

**Пресет** — готовый текст для поля «**Вход модели**» и параметры запроса. `F4` открывает список, стрелки выделяют вариант, `Enter` загружает его. Загрузка полностью заменяет текст и параметры и очищает поле «**Выход модели**». `Esc` закрывает список без применения.

Сразу после выбора нажми `F5`: текст будет отправлен модели, а её ответ появится в поле «**Выход модели**». `F6` останавливает выполнение. Сейчас осваиваем только выбор, запуск и чтение ответа; устройство модели разберём позже.

**Попробуй**

Нажми `F3`, открой `F4`, выбери интересующий пресет и нажми `Enter`. Сразу нажми `F5`, дождись ответа и прочитай поле «**Выход модели**». Затем вернись в `F2`.

**Вопрос после опыта**

Какой вопрос ты выбрал и что ответила модель? Какое действие загрузило заготовку, а какое отправило запрос?

## Ожидаемые наблюдения

Загрузка заменяет поле «**Вход модели**», параметры и очищает поле «**Выход модели**». Только `F5` вызывает модель. Точный текст ответа не задан заранее.

## Если результат отличается

Ошибка соединения — отсутствие полученного ответа. Обратись к преподавателю; не считай ошибку ответом модели. Необычный ответ — результат для чтения, его не надо исправлять до заранее заданного текста.

## Свой эксперимент

После основного запуска выбери другой пресет и проверь, что старый ответ исчез при загрузке. Затем можешь выполнить новый запрос.

## Что сохранить

Лаборатория сохраняет состояния и запросы в журнале новой сессии; прежние сессии не удаляются.

## Критерии завершения

Ты выбрал пресет, получил настоящий ответ и отличаешь подготовку от выполнения. Преподаватель сверяет журнал и ответы и объявляет завершение.
