# Урок 00. Освоиться в интерфейсе

Короткое знакомство примерно на **10 минут**. Начни с [введения](INTRO.md), которое автоматически появится в терминале преподавателя. **Разговариваем только в канале преподавателя.** Терминалы нужны для материалов и опытов.

## Цель

Освоить два окна, простое переключение, помощь и одну команду просмотра. Понять, куда вводить команду и где задать вопрос. Модель в этом уроке не участвует.

## Перед началом

Нужны tmux и зависимости интерфейса из requirements.txt. Веса, сервер модели, Docker и API не нужны. Если преподаватель подготовил сессию, используй его команду подключения. Самостоятельный запуск из обычного Bash:

```bash
cd /path/to/llm2harnes
./lab classroom start --lesson 00 --split
```

Вопросы, ответы и объяснения пиши только в канале преподавателя. Не копируй туда весь вывод: преподаватель сам читает журнал команд. Специального сигнала для продолжения нет — достаточно обычной реплики о результате или затруднении.

## План занятия

| Шаг | Действие | Признак результата |
|---|---|---|
| 1 | F3, затем F2 | Курсор и выделенная рамка меняют окно. |
| 2 | Ctrl+h, затем Esc | Справка появляется и закрывается. |
| 3 | F3, затем show | Видны две строки учебного текста; модель не вызывается. |

Это полный план. Команда doctor относится к подготовке модели в уроке 01; здесь она не требуется. Прокрутка доступна колесом мыши и не является отдельным экзаменом.

## Опыты

### 1. Выбрать окно

**F3** сразу выбирает терминал ученика с приглашением `ученик>`. **F2** сразу возвращает к материалам преподавателя. Нажимай каждую клавишу один раз. Можно также щёлкнуть по окну мышью.

Посмотри, как меняются курсор и выделенная рамка. Здесь в чате расскажи, получилось ли переключиться. Преподаватель подтвердит результат и предложит следующий шаг.

### 2. Открыть помощь

По предложению преподавателя нажми **Ctrl+h**. В отдельном окне появится справка. **Esc** закрывает её и возвращает к прежнему вводу. Для чтения длинного текста в справке есть стрелки и PgUp/PgDn. Сочетание помощи постоянно указано в нижней плашке.

### 3. Посмотреть учебный текст

`show` означает «показать подготовленный текст». Выбери терминал ученика клавишей F3 и введи:

```text
show
```

Команда только показывает текст; запроса к модели нет. Найди блок **«ТЕКСТ ДЛЯ МОДЕЛИ — ВХОД»** и прочитай две строки внутри него. Здесь в чате объясни, что увидел. Преподаватель прочитает соответствующее событие сам и поможет отличить подготовленный вход от ответа модели.

## Ожидаемые наблюдения

Материалы и подсказки находятся в терминале преподавателя, команды и результаты — в терминале ученика. Вопросы обсуждаются в канале преподавателя. Справка не меняет подготовленный текст; show не вызывает модель.

## Если результат отличается

- Непонятно действие или результат: спроси в канале преподавателя, преподаватель разберёт именно это место.
- Сложно выбрать окно: используй F2 или F3, либо щелчок мыши.
- В материалы введена обычная фраза: программа напомнит о чате и не будет изображать доставку сообщения преподавателю.
- Неясно, что показал show: назови непонятный блок; ответ модели для этого упражнения не нужен.

## Что сохранить

Команды и обращения к справке автоматически сохраняются в `results/classroom/ИДЕНТИФИКАТОР`. Разговор остаётся в канале преподавателя. Преподаватель фиксирует итог с указанием фактически выполненных действий.

## Критерии завершения

1. Ты переключаешь окна по F2/F3 и различаешь их назначение.
2. Открываешь помощь и возвращаешься по Esc.
3. Выполнил show и своими словами отличаешь подготовленный текст от ответа модели.

После этих трёх шагов преподаватель явно объявляет **«Урок 00 завершён»**. Новые обязательные задания к этому уроку после этого не добавляются. Затем можно выйти: F2, команда `/exit`. Журнал сохраняется, остановка активного опыта проверяется отдельно.

## Свой эксперимент

При желании выбери окно мышью и сравни с F2/F3. Это необязательный опыт, он не задерживает завершение урока.
