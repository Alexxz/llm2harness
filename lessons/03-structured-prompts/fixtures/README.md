# Искусственные входы для проверки оценивания

Все заявки, ожидаемые значения и ответы в этом каталоге заданы автором. Это не сохранённые запросы к модели и не измеренные результаты её работы.

`evaluation-cases.json` задаёт шесть проверочных задач. В `responses` находятся пять служебных оболочек, похожих по форме на выход клиента, с преднамеренно выбранными ошибками:

| Файл | Содержание |
|---|---|
| c01.json | Верные JSON, схема и значения. |
| c02.json | Корректный JSON с числом, записанным строкой; схема не проходит. |
| c03.json | Пояснение перед JSON; текст целиком не является JSON. |
| c04.json | JSON проходит схему, но напиток не соответствует заявке. |
| c05.json | Верный ответ с `null` для недопустимого количества. |
| c06.json | Файл намеренно отсутствует, чтобы проверить учёт незавершённой серии. |

Ожидаемый отчёт на этой фикстуре: 6 задач, 5 доступных файлов, 4 разбираемых JSON, 3 соответствия схеме, 2 правильных содержательных ответа. Эти счётчики описывают созданную фикстуру.
