Создай короткую учебную заметку с содержимым «Сессия продолжена.» в рабочем каталоге. Имя файла пока не согласовано.

Сначала спроси у пользователя имя файла и дождись ответа. Для этого используй действие ask_user с arguments.questions, содержащим готовый вопрос. Ничего не записывай до получения имени.

После ответа создай ровно названный пользователем файл через write_file, прочитай его через read_file и только затем заверши задачу через finish. Не используй shell: для этой заметки достаточно инструментов файлов. В заключении укажи имя и фактически прочитанное содержимое. Формат действий задаёт harness.
