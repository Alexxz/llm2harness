# Подготовка урока 02

Продолжаем с тем же локальным профилем Qwen2.5-1.5B **base** Q4_K_M и llama.cpp b12380, что использовали в уроке 01. Новые веса, обучение, контейнер или платный API не нужны. Команда запуска урока сама поднимет остановленный сервер, проверит профиль и настоящий ответ, а также доступность преподавателя. Уже проверенные веса повторно не скачиваются. Если весов или runtime нет, они подготавливаются по фиксированному профилю; системные требования описаны в разделе «Запуск» README.

Настройки урока заранее выбраны: temperature=0, seed=42, max_tokens=24. Кандидаты проверены на настоящей модели в `evidence/lesson-02-example-selection.json`. Это авторский пилот выбора примера, не практика ученика и не полный педагогический прогон.

В обычном терминале из корня проекта:

```bash
./lab classroom start --lesson 02 --split
```

Внутри F3 вводятся команды учебной программы, а не Bash. Первый экран объясняет show; после показа готовая карточка позволит получить результат без ожидания агента на детерминированной операции. Диалог преподавателя и ответы ядра — разные каналы; левый чат не добавляется к правому запросу автоматически.

Полный авторский маршрут сохранён в evidence/lesson-02-live-pilot.json: шесть настоящих запросов через учебную консоль, включая edit полного второго входа. Вопрос с историей и без неё имеет одинаковый конечный текст, включая перевод строки после «Ответ:». Начало урока отдельно проверено в настоящем tmux; подробности в results/lesson-02-terminal-pilot.json. Эти прогоны не заменяют твоё собственное прохождение.
