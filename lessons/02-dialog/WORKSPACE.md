# Работа в лаборатории

Урок 00 уже познакомил ученика с областями, F1/Esc, выбором пресета и первым F5. Не повторяй экзамен по интерфейсу. Объясняй только новое для текущей фазы. Пресет заменяет вход и параметры и очищает выход; любые сравнения восстанавливай из сохранённых запросов и ответов, не требуй помнить исчезнувший текст. Непредсказанный ответ допустим, ошибка запуска не является ответом.

`F4` открывает список, `Enter` полностью загружает пресет без запуска, `Esc` отменяет выбор. `F5` выполняет, `F6` останавливает. `Tab` выбирает поле. Следуй текущей инструкции, не выполняй будущие шаги заранее.
