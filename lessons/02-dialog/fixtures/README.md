# Дополнительный рендер учебной переписки

Основной маршрут урока использует короткие тексты в prompts и штатные show/load/edit/run. Он не требует запускать dialog.py.

messages.json и start.json оставлены для дополнительного технического опыта с dialog.py: программа превращает список ролей в текст и может добавить сохранённый настоящий ответ. Реплика «Принято» в messages.json задана автором, а не получена от модели; её нельзя засчитывать как настоящий ход ученика. Метка ЛИПА-7429 — выдуманное публичное значение.

Эти файлы не являются источником baseline/variation новой версии урока. Их рендер имеет другой буквальный формат входа. При дополнительном сравнении сохраняй этот формат одинаковым на обеих сторонах.
