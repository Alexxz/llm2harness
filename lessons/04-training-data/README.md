# Маленькое настоящее обучение: до и после

## Цель

На знакомой заявке о напитке увидеть разницу между примером во входе и изменением параметров: получить ответ, задать учебные пары, действительно обучить добавку и повторить тот же запрос.

## Перед началом

Урок 03 завершён. Подготовленная маленькая Qwen 0.5B работает локально на CPU; преподаватель использует отдельное подключение ученика. Эта модель уже проходила instruction tuning. Её смена с прежней 1.5B — выбор профиля, а не результат обучения. Внутри опыта до/после остаётся один checkpoint.

Запуск: ./lab classroom start --lesson 04 --split. Старую сессию можно закрыть через /exit; её результаты сохраняются. Новый практикум открывается F8. Он сам подписывает текущее действие F5. Esc сохраняет место и возвращает к преподавателю F2. Повторный F8 открывает сохранённый опыт.

## План занятия

| Время | Наблюдаемый опыт |
|---|---|
| 0–15 мин | Ответ до и одна понятная учебная пара; всего четыре пары видны рядом. |
| 15–30 мин | Реальное короткое обучение с прогрессом и обсуждением. |
| 30–45 мин | Тот же вход после; добровольное отключение добавки. |
| 45–60 мин | Новая заявка и смысл отдельной проверки. |
| до 90 мин | Вопросы и добровольное изменение желаемого ответа в отдельном опыте. |

## Опыты

Весь маршрут — один экран F8. F5 выполняет только подписанный текущий шаг: ответ ДО → подтвердить пары → начать ОБУЧЕНИЕ → ответ ПОСЛЕ → показать новую заявку → ответить на новую заявку → итог и возвращение в F2.

F6 останавливает выполняющийся опыт. F4 показывает точные входы, настройки и технические сведения. На шагах до/пары F7 позволяет добровольно заменить заявку или первую желаемую строку. Во время обучения пары уже зафиксированы. На сравнении F8 внутри практикума повторяет исходный запрос без добавки.

Просмотр пары не меняет веса. F5 на шаге обучения запускает настоящее обновление LoRA-добавки. F5 после обучения отправляет прежний вход, в котором нет готового ответа или учебных пар. Сравнение использует исходные тексты, без вырезания JSON из Markdown.

## Ожидаемые наблюдения

В авторском замере обучение четырёх пар за 12 шагов заняло около 19 секунд, без установки и скачивания. До обучения модель добавляла Markdown вокруг JSON, после выдала чистый JSON; при отключении добавки вернулся прежний ответ. Это наблюдение, а не обещание идентичного результата или общего улучшения. Исходные веса остаются фиксированными; изменяются параметры небольшой добавки.

## Если результат отличается

Обучение может изменить параметры, но не улучшить конкретный ответ. Это разные проверки. Незавершённый процесс не считается обученной добавкой. Ошибка, остановка и частичный результат отображаются явно. Проверка формы не гарантирует смысл. На «я потерялся» преподаватель возвращается к одной видимой заявке и текущему изменению, а не даёт список команд или экзамен.

## Что сохранить

Стенд сохраняет заявку, четыре пары, ответы до/после, прогресс, файл добавки и техническое подтверждение изменения параметров. Новый запрос и отключение записываются отдельно. Закрытие F8 сохраняет место. Исторические data/baseline/report из прежнего маршрута не требуются.

## Критерии завершения

Есть настоящий ответ до, подтверждённые пары, завершённое реальное обучение, тот же запрос после и первая проба новой заявки. Ученик на своём наблюдении различает изменение входа и обучение. Кнопки сами не доказывают понимания; идеальный JSON или заученное определение eval не нужны.

## Свой эксперимент

До обучения F7 меняет первую желаемую строку. Можно обсудить, что случится при неверном желаемом ответе. Это добровольно: первый проход уже содержит полный опыт. Новый пример не использовался в обучении; имена train/eval появляются после наблюдения, а более строгая проверка продолжится в уроке 05.
