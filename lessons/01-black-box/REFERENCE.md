# Модель как чёрный ящик

Для совместной работы открой [учебную консоль с преподавателем](../../course/TERMINAL_CLASSROOM.md): `./lab classroom start --lesson 01` из корня проекта. Промпты, явные запуски и советы этой сессии видны преподавателю; обычные команды других терминалов в журнал не попадают.


## Цель

Получить собственные ответы модели и проследить весь путь от файла с промптом до файла с результатом. После занятия ты сможешь отличить веса модели, программу запуска и клиент запроса, а также объяснить, что изменилось в каждом опыте.

В этом занятии модель доступна через операцию «текст на входе — текст на выходе». Её устройство внутри не исследуем. Значение `max-tokens` понадобится только как ограничение длины продолжения: токен здесь достаточно понимать как фрагмент текста.

## Перед началом

Работай из корня проекта. По ресурсному плану курса должны быть отдельно подготовлены веса и запущен сервер llama.cpp на `http://127.0.0.1:8088`. Загрузка весов и установка среды относятся к подготовке, а не к 75 минутам этого занятия.

```bash
/usr/bin/python3 -m coursekit doctor
/usr/bin/python3 -m coursekit prompt 01 baseline
mkdir -p results/01
cp lessons/01-black-box/run-card.json results/01/run-card.json
```

Заполни копию карточки запуска: название и ревизию весов, вариант base или instruct, квантование, версию runtime и оборудование. Преподаватель помогает найти значения в утверждённом профиле запуска. Не заменяй неизвестные значения догадками: отметь их как неизвестные и выясни до сравнений между моделями.

Базовая версия предварительно обучена продолжать текст. Версия для инструкций дополнительно обучена выполнять запросы. Обе можно вызвать без инструментов и агентного цикла. В этом занятии используется один выбранный профиль; переход к другой версии будет отдельным отмеченным изменением, а не скрытой частью опыта.

## План занятия

| Время | Работа |
|---|---|
| 0–10 минут | Проверить стенд, прочитать промпт и записать прогноз. |
| 10–25 минут | Получить исходное продолжение и повторить запрос. |
| 25–40 минут | Изменить только формулировку промпта. |
| 40–60 минут | Сравнить параметры генерации и ограничение длины. |
| 60–75 минут | Разобрать сохранённые результаты и предложить свой опыт. |

## Опыты

### Исходное продолжение

Прочитай [исходный промпт](prompts/baseline.txt). До запуска запиши в `results/01/observations.md`: продолжит ли модель рассказ, станет ли отвечать как помощник, сколько предложений ожидаешь и почему.

```bash
/usr/bin/python3 -m coursekit complete --prompt-file lessons/01-black-box/prompts/baseline.txt --endpoint http://127.0.0.1:8088 --max-tokens 32 --temperature 0 --seed 42 --output results/01/baseline-a.json
jq -r '.text' results/01/baseline-a.json
```

Открой JSON результата целиком. Найди продолжение в `text`, сведения о запросе в `metadata` и сопоставь их с командой. Полный вход — содержимое файла промпта. Сохранённый ответ не подтверждает, что модель открывала файлы или выполняла действия, о которых написала: в этом опыте клиент только отправляет текст серверу.

### Повтор того же запроса

До повторного запроса предположи, совпадёт ли ответ. Не меняй файл, профиль сервера или настройки.

```bash
/usr/bin/python3 -m coursekit complete --prompt-file lessons/01-black-box/prompts/baseline.txt --endpoint http://127.0.0.1:8088 --max-tokens 32 --temperature 0 --seed 42 --output results/01/baseline-b.json
/usr/bin/python3 lessons/01-black-box/compare.py results/01/baseline-a.json results/01/baseline-b.json
```

Сравнивается только `text`: служебные поля времени могут различаться. Совпадение текста — наблюдение для данной конфигурации, а не обещание побитовой воспроизводимости на любом оборудовании. При различии сначала проверь карточку запуска, фактический промпт и параметры.

### Меняем только промпт

Во [втором промпте](prompts/variation.txt) заменено только cat на house; образец и остальные строки сохранены. Веса, сервер, длина, температура и seed остаются прежними.

```bash
diff -u lessons/01-black-box/prompts/baseline.txt lessons/01-black-box/prompts/variation.txt
/usr/bin/python3 -m coursekit complete --prompt-file lessons/01-black-box/prompts/variation.txt --endpoint http://127.0.0.1:8088 --max-tokens 32 --temperature 0 --seed 42 --output results/01/variation.json
/usr/bin/python3 lessons/01-black-box/compare.py results/01/baseline-a.json results/01/variation.json
```

Проверь, изменился ли перевод вслед за английским словом. Если перевод неверен или модель пишет следующие пары, сохрани этот результат. Базовая версия может продолжать текст иначе, чем ожидает пользователь; это полезное свидетельство её поведения. Замена слова во входе не является дообучением.

### Меняем температуру при одинаковых seed

Увеличение температуры меняет выбор продолжения. Оно не добавляет знаний и не гарантирует разнообразия в каждом запросе. Для сравнения выполни короткую серию с одинаковым набором seed в обеих группах:

```bash
for seed in 7 42; do
  /usr/bin/python3 -m coursekit complete --prompt-file lessons/01-black-box/prompts/baseline.txt --endpoint http://127.0.0.1:8088 --max-tokens 32 --temperature 0 --seed "$seed" --output "results/01/cold-$seed.json"
  /usr/bin/python3 -m coursekit complete --prompt-file lessons/01-black-box/prompts/baseline.txt --endpoint http://127.0.0.1:8088 --max-tokens 32 --temperature 0.9 --seed "$seed" --output "results/01/warm-$seed.json"
done
```

Сравни пары с одинаковым seed. Затем посчитай число различных текстов внутри каждой группы. Нулевая разница при такой маленькой серии допустима: запиши её и предложи, как увеличить чувствительность опыта, не меняя сразу несколько параметров. Эта серия показывает поведение на одном входе, а не общую оценку качества модели.

### Ограничение длины

Снова используй исходный промпт, температуру 0 и seed 42. Меняется только верхний предел продолжения.

```bash
/usr/bin/python3 -m coursekit complete --prompt-file lessons/01-black-box/prompts/baseline.txt --endpoint http://127.0.0.1:8088 --max-tokens 8 --temperature 0 --seed 42 --output results/01/short.json
jq -r '.text' results/01/short.json
```

Сопоставь ответ с исходным запуском и служебными данными. Короткий лимит может оборвать предложение. Ответ может завершиться раньше предела; предел не требует выдавать ровно заданное число фрагментов текста.

## Ожидаемые наблюдения

У тебя появятся настоящие ответы модели и точные входы к ним. Изменение промпта и настроек может менять продолжение без изменения весов. Вызов `complete` не включает автоматический цикл инструментов, проверку истинности или работу с проектом.

Форма продолжения и степень разнообразия зависят от выбранной модели. Ожидаемый результат занятия — воспроизводимая постановка сравнения и корректное объяснение результатов, включая совпадение или ошибочный перевод, а не заранее выдуманный ответ.

## Если результат отличается

- Соединение не установлено: вернись к подготовке сервера. Сбой транспорта не считается ответом модели.
- Продолжение пустое: проверь сведения о завершении и достаточность лимита. Сохрани исходный результат до изменения параметров.
- Ответ выглядит как новый вопрос или длинная статья: проверь вариант модели и весь текст входа. Обсуди, почему продолжение текста не обязано вести себя как чат.
- При повторе изменился ответ: сравни фактические параметры и профиль. Не делай вывода, что модель «научилась за один запрос».
- Высокая температура не изменила три ответа: это результат данной серии. Для следующего опыта можно увеличить число повторов или выбрать более открытое начало, изменяя один фактор за раз.

## Что сохранить

Сохрани `run-card.json`, все полученные JSON-ответы и `observations.md` с таблицей: имя запуска, гипотеза, изменённый фактор, наблюдение, вывод. Если изменял файл промпта, положи его копию рядом с результатом. Для сравнения текстов разрешён [compare.py](compare.py): он читает только уже сохранённые результаты.

## Критерии завершения

1. Есть минимум два реальных запроса с одинаковыми входами и одна пара с единственным изменением промпта.
2. Есть сравнение температуры при совпадающих seed и один опыт с коротким ограничением длины.
3. Карточка позволяет определить использованную модель и программу запуска; неизвестные данные явно отмечены.
4. Ты можешь показать исходный текст, параметры и ответ для каждого вывода.
5. Ты объясняешь, почему смена промпта, версия для инструкций и самостоятельный агент — разные вещи.

При ограничении времени серию температуры можно сократить до двух seed. Наличие проверок файлов без реального запроса к модели не закрывает практику с моделью.

## Свой эксперимент

Предложи изменение одной строки промпта, которое должно повлиять на ответ: язык, адресат, длина, стиль или формат. Запиши прогноз, проведи пару запусков при одинаковых остальных условиях и приведи пример результата, который опроверг бы твой прогноз.
