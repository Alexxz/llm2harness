# Урок 01. Модель как чёрный ящик

В уроке 00 ты уже выбрал пресет и получил ответ через `F5`. Теперь посмотрим, что именно делает модель с переданным текстом. Она создаёт продолжение поля «**Вход модели**»: в этом примере оно заканчивается началом перевода. Внутри модели есть обученные числовые параметры — **веса**. Обычный запрос их не меняет; текст ответа сам по себе не исполняется как программа.

Текущий шаг объяснит преподаватель. Смена пресета очищает «**Выход модели**», а история остаётся у преподавателя. `F2` — обсуждение, `F3` — лаборатория, `F1` — подсказка.
