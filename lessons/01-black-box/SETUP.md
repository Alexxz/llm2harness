# Подготовка к уроку 01

Это работа до занятия. Вызовы codex относятся к преподавателю и не заменяют исследуемую модель. Для ядра используем локальный llama.cpp и фиксированный профиль Qwen2.5 1.5B **base**, без инструментов и чат-шаблона. Сервер получает точный текст через /completion.

Модель уже подготовлена на этом ноутбуке: файл скачан, размер и SHA256 проверены, настоящий запрос сохранён в evidence/lesson-01-preflight-v2.json. Если сервер ещё работает, можно сразу открыть урок. Ниже — инструкция для повторной подготовки после остановки или переноса. Загрузка занимает примерно 986 MB; уже проверенный файл повторно не скачивается.

Все команды этой страницы вводятся в **обычном Bash**, не в `ученик>`.

## 1. Подготовить веса

Посмотреть план без скачивания:

```bash
cd /path/to/llm2harnes
/usr/bin/python3 tools/prepare_model.py --variant base
```

Чтобы скачать фиксированную ревизию и проверить размер и SHA256:

```bash
/usr/bin/python3 tools/prepare_model.py --variant base --download
```

При незавершённой предыдущей загрузке программа сохранит её и остановится; не выдаст неполный файл за готовый. Не удаляй такие файлы вслепую. Профиль и контрольная сумма находятся в resources/models.json.

## 2. Запустить сервер

В отдельном обычном терминале:

```bash
cd /path/to/llm2harnes
runtime/llama-b12380/llama-server \
  --model models/qwen2.5-1.5b-base-q4_k_m.gguf \
  --host 127.0.0.1 --port 8088 --ctx-size 4096 --threads 4 --device none
```

Терминал остаётся занят сервером. Во время урока он должен работать. Не переключай модель между сравниваемыми запросами. После урока Ctrl+c здесь останавливает сервер; /exit в классе его не останавливает.

## 3. Проверить настоящий ответ

В другом обычном терминале:

```bash
cd /path/to/llm2harnes
./lab complete --prompt-file lessons/01-black-box/prompts/baseline.txt \
  --endpoint http://127.0.0.1:8088 --max-tokens 32 \
  --temperature 0 --seed 42 --output evidence/lesson-01-preflight-v2.json
```

Проверь text и metadata. Это первый запрос подготовки, не опыт ученика в классе. Сохрани ошибку при её наличии: без успешного соединения и генерации практическая готовность не подтверждена. Наличие файлов или успешный ответ преподавателя не заменяют этот запрос.

В копию run-card.json внеси профиль из resources/models.json, фактическую версию runtime и оборудование. Сохрани рядом с результатом подготовки. Шаблон карточки не является заполненной карточкой.

## 4. Открыть урок

```bash
./lab classroom start --lesson 01 --split
```

Первое задание появится сразу. Слева сообщи преподавателю, если подготовка ещё не завершена. Перед первым run он откроет допуск к опытам. Внутри класса работают только учебные команды, которые он объясняет по одной.

Сервер слушает localhost; внешняя аренда и платный API для этого варианта не нужны. Требуемое оборудование и альтернативы описаны в course/PREPARATION.md. Вопрос подписки и API-биллинга остаётся отложенным.
