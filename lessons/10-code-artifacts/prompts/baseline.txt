Создай в рабочем каталоге файл greet.sh на Bash.
Контракт:
- ровно один аргумент — имя, которое является данными;
- stdout: Привет, <имя>! и ровно один перевод строки, exit code 0;
- при нуле или нескольких аргументах stdout пуст, stderr: usage: greet.sh NAME и перевод строки, exit code 2;
- имя с пробелами, пустая строка и символы оболочки должны сохраняться буквально;
- никакой сети, внешних сервисов, установки программ и чтения за пределами рабочей области.
Используй разрешённые действия harness. В конце перечисли созданные файлы и фактически выполненные проверки. Не называй невыполненные проверки успешными.
