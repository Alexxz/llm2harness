# Сторонние компоненты

Собственный код и учебные материалы распространяются по [0BSD](LICENSE), без гарантий. Сторонние компоненты сохраняют собственные лицензии; лицензия проекта их не заменяет.

Веса не включены в репозиторий. Ревизии и источники указаны в [resources/models.json](resources/models.json). Qwen2.5-1.5B, Qwen2.5-1.5B-Instruct и Qwen2.5-0.5B-Instruct опубликованы с Apache-2.0; при загрузке и распространении сверяйте LICENSE и NOTICE выбранного upstream и конвертации GGUF. Уроки используют их через llama.cpp (MIT) и библиотеки Python с отдельными условиями.

Codex — внешний инструмент; доступ к нему и к API определяется условиями соответствующего поставщика. Вызовы могут расходовать лимиты или деньги ученика. OpenSpec и зависимости образа устанавливаются из внешних источников на их условиях; см. containers/Dockerfile. Реализация учебного навыка GrillMe написана внутри проекта, её название описывает метод интервью.
